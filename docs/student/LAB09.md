# LAB09 — Deadlock

## Objective
Create a reproducible deadlock and identify the cyclic dependency.

## Student Instructions
1. Open two SSMS sessions.
2. Run Session A updating Customers then Orders.
3. Run Session B updating Orders then Customers.
4. Start them close together.
5. Identify the deadlock victim and SQL error 1205.
6. Propose a consistent resource access order.

## Deliverable
Record observations, evidence and a short conclusion for the lab.
