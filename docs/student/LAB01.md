# LAB01 — From HTTP Request to SQL Server

## Objective
Trace the complete path from an HTTP request through ASP.NET Core and EF Core to SQL Server.

## Student Instructions
1. Start the lab environment and run the API.
2. Call `GET /workshop1/customers-bad` from Swagger.
3. Find `Microsoft.EntityFrameworkCore.Database.Command` in the application log.
4. Copy the generated SQL and identify the main table, joins, selected columns and row limiting.
5. Open `Workshop1Endpoints.cs` and identify which LINQ operations build the query and which operation causes execution.
6. Run an equivalent query in SSMS and compare it with the SQL generated by EF Core.

## Deliverable
Record observations, evidence and a short conclusion for the lab.
