# LAB12 — Final Challenge: Developer Meets DBA

## Objective
Combine application, execution-plan, indexing, Query Store and concurrency skills into one assessment.

## Student Instructions
1. Review the intentionally problematic endpoints.
2. Use Query Store, plans, STATISTICS IO/TIME, waits, blocking and locks.
3. Classify every finding as Application, Database or Both.
4. Assign Impact and Effort.
5. Prepare a prioritized remediation table.
6. Answer: 'What really reaches SQL Server?'

## Deliverable
Record observations, evidence and a short conclusion for the lab.
