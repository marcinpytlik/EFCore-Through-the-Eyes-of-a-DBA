# LAB10 — Query Store Basics

## Objective
Use Query Store to find expensive application queries.

## Student Instructions
1. Generate workload using the Workshop 4 bad endpoint and Workshop 2 endpoint.
2. Open Query Store → Top Resource Consuming Queries.
3. Locate queries touching Customers, Orders and OrderLines.
4. Run `sql/05_Diagnostics.sql`.
5. Record query_id, executions, duration, CPU and logical reads.

## Deliverable
Record observations, evidence and a short conclusion for the lab.
