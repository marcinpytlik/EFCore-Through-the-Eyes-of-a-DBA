# Workshop Assessment Rubric

| Area | 0 pts | 1 pt | 2 pts | 3 pts |
|---|---|---|---|---|
| SQL generated by EF Core | Cannot identify | Identifies SQL only | Connects LINQ to SQL | Explains query shape and consequences |
| Execution plans | Cannot read operators | Recognises Scan/Seek | Explains Lookup/estimates | Uses plan evidence for fix |
| Indexing | No useful proposal | Index without evidence | Useful key choice | Balances covering benefit and cost |
| Transactions / blocking | Cannot identify blocker | Finds blocker | Explains lifetime | Proposes safe correction |
| Isolation / deadlocks | Confuses concepts | Recognises concept | Explains dirty read/cycle | Prevention + retry strategy |
| Query Store | Cannot locate query | Finds query | Reads metrics | Uses it to validate fix |
| Root cause analysis | Guesses | Weak explanation | Uses evidence | Correctly separates Application/Database/Both |
| Validation | None | Subjective | One metric | Multiple independent evidence points |

Maximum: **24 points**

- 21–24: Excellent
- 17–20: Very good
- 13–16: Good
- 9–12: Basic pass
- 0–8: Needs further practice
